# Sistem Logika Fuzzy Kipas

Program ini menghitung rekomendasi kecepatan kipas (RPM) berdasarkan suhu (20–40 °C) dan kelembapan (40–80%). Hasil perhitungan dibandingkan menggunakan metode Mamdani, Sugeno, dan Tsukamoto.

## Menjalankan

```bash
pip install -r requirements.txt
python main.py
```

Gunakan `python main.py --manual` untuk memasukkan suhu dan kelembapan sendiri. Jalankan `python analisis.py` untuk analisis dan grafik.
